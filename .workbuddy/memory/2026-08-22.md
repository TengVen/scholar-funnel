## 修复：CREATE TRIGGER 幂等化（10:11-10:15）

用户执行 PG DDL 时报错 `function set_updated_at() does not exist`（单独执行非 00 文件时函数未建）。

### 问题
- 00_init.sql 定义函数，其他文件单独跑时函数不存在 → CREATE TRIGGER 失败
- 且 PG 的 CREATE TRIGGER 无 IF NOT EXISTS → 重跑会报 already exists（DDL 非幂等缺陷）

### 修复
- 4 个 DDL 文件（01_sys/02_users/03_agents/04_core）共 10 个 CREATE TRIGGER 全部改为 DO $$ 块 + pg_trigger 存在性检查（幂等）
- 影响范围说明：trigger 失败只影响 updated_at 自动刷新，表结构/数据/外键正常
