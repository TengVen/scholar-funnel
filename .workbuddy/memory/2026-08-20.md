  - 用 mysql CLI 读取含反斜杠/美元符的摘要（Windows 下输出 GBK 编码，需 encoding="gbk" errors="replace"）

- Windows 下 mysql CLI 输出是 GBK：subprocess 读取用 encoding="gbk" errors="replace"

- managed python 无项目依赖（httpx/sqlalchemy），独立脚本用 mysql CLI 最稳
